Task Drop — endpoint test

Runs the same three transports the R1 app uses, in the same order, and tells you which ones your Apps Script deployment accepts. Each passing test writes one row to your sheet.

POSTnot run
GETnot run
NO-CORSnot run
BAD KEYnot run

Serve this page over http://localhost rather than opening the file directly — a file:// page has a null origin and some browsers treat it differently from the R1 WebView. From the repo folder: python -m http.server 8080, then open http://localhost:8080/endpoint-test.html.

BAD KEY is the one test that should fail. If it passes, your Apps Script is not checking the key and anyone with the URL can write to your sheet.
